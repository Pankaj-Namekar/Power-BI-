# Power BI End to End Project

Full business-intelligence case studies: business requirements, data model, branding, and the final Power BI report, not just a single dashboard file.

## Hospitality-Airbnb Project
A star-schema data model built from Airbnb-style listing and booking data (dim_date, dim_host, dim_location, dim_property, fact_bookings), with a business requirements document, data dictionary, and a custom Power BI theme and canvas background.

## Ecomm-Walmart Project
A retail analytics case study with a star-schema model (Customer, Employee, Product, and Store dimensions, plus a Sales fact table), a business requirements document, developer guidelines, and custom branding.

## End to End Project.pbix
The combined Power BI report file tying the case studies together. Open it in Power BI Desktop to explore the full model and report pages.

Each subfolder has its own README with more detail.
