# Walmart Project

An end-to-end Power BI case study modeled on Walmart-style retail sales data.

## Contents
* Walmart_BRD.pdf: business requirements document defining the scope and goals of the analysis.
* Walmart_BI_Developer_Guidelines.pptx: development standards and conventions used to build the report.
* Walmart Canvas Background.svg: a custom report canvas background.
* Logo.png: brand logo used in the report.

## Data model (star schema)
* Sales_Fact.zip: the fact table of sales transactions (zipped CSV).
* Customer_Dim.csv, Employee_Dim.csv, Product_Dim.csv, Store_Dim.csv: supporting dimension tables.

## How to use
1. Read Walmart_BRD.pdf for context on what the report answers.
2. Unzip Sales_Fact.zip and import it alongside the dimension CSVs into Power BI Desktop.
3. Build relationships per the star schema and follow Walmart_BI_Developer_Guidelines.pptx for report standards.

The finished report lives at End to End Project/End to End Project.pbix.
