# Standalone Reports & Templates

Standalone Power BI reports and templates that aren't part of a full end-to-end case study.

* LinkedIn-Report.pbit: a reusable LinkedIn analytics report template.
* MOM Comparision with CF.pbix: month-over-month comparison report using custom formatting.
* Waterfalls using Visual calculations.pbix: waterfall charts built with Power BI's visual calculations feature.

Open any `.pbix` file directly in Power BI Desktop. `.pbit` files are templates: opening one in Power BI Desktop will prompt you to connect your own data source.
