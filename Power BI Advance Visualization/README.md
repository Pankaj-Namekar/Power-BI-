## Build Visuals with Just SVG \+ DAX — No Custom Visuals Needed

Everyone installs a custom visual for this. You don't need to. 👇

You can build clean, animated, colour-coded visuals in Power BI using just **SVG and DAX** — no custom visuals, no imports, no extra licensing.

A 2-part series that takes you from zero to pro:

- 🟢 **Part 1 — The Basics** What SVG actually is (explained simply), and how to build Status & Priority pills that make any table look 10x better. ▶️ [https://youtu.be/lo9NTrbGc4Y?si=IjakXyvHV9kbhG7s](https://youtu.be/lo9NTrbGc4Y?si=IjakXyvHV9kbhG7s)  
    
- 🔵 **Part 2 — Level Up** Animated progress bars, donut KPIs, and a car-style dashboard gauge — all Target vs Actual, all pure DAX. ▶️ [https://youtu.be/617ufrmWYZU?si=XIoMndd8moXZw5oG](https://youtu.be/617ufrmWYZU?si=XIoMndd8moXZw5oG)

The best part? Once you understand the pattern, you can build almost any visual you can imagine — and even use AI to write the DAX for you.

Save this. Try it. Your reports will never look the same. 🚀
